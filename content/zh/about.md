# 关于我

2019年毕业以后，我以独立游戏美术的身份入行，花了大量时间学习手绘技巧。我很快发现自己倾向于在项目中进行“补位”，具体来说，在做UI的时候，我意识到在策划文档和UI美术之间，还应该存在着一个交互设计师的角色。我希望事情能做完，就要填补这些缝隙。这样的工作对于我来说还有宣传kv、表情包、甚至有些时候，地编。
我有很多困惑。我害怕自己不够”细分“，找不到自己的“职业定位”。于是2022年我投递了一家出海手游的UI岗位。然后又因为一些机缘巧合，加入了一家单机游戏发行公司。我承担了平面设计、社区运营、市场营销等多个维度的工作，参与了多款单机游戏的上线。我认真对待每一份职责，也得到了团队的认可。我发现自己有能够将事情推动的工作素养。但是很奇怪，我的初衷是有个声音告诉我，我不够“细分”，不够“专业”，但是结果却是我尝试了更多岗位。我仍然困惑。
2025年，我回到学校里，进入游戏设计研究生专业。校区在北欧的一座小岛上，坐船要40分钟才能到大陆。我在学校里认识了很多朋友，我们玩了很多游戏，我和朋友们玩dnd，玩apex legend，玩博德之门3。我们也做了很多的小项目。我们所有人都有机会作为游戏设计师，考虑我们的游戏想要给玩家带来什么样的体验，也考虑游戏作为媒介，能达成什么事情，传达什么信息，以及我们自己想要传达什么信息。在我参与的项目中，[有的](https://tianyun-yang.itch.io/lost-in-the-subway-v2)尝试使玩家在宣泄夺回一些主体性，[有的](https://ventiwang.itch.io/incubator)通过创造遭遇学术剽窃的体验来比喻一些不公，有的桌游让玩家们通过互相指责感觉不适，还有solo的[电子互动小诗](https://tianyun-yang.itch.io/the-hole-on-the-road)，我尝试描述一个在工作和日常中感觉疲惫的人，ta内心的空洞显现在工作道路前，直到ta无法再忽视它，跳进奇怪的洞中探索。
在登岛之前，我心里想的是，我这次一定要在市场中给自己找到一个“立足之地”。但是我发现，这一年里我获得的是“创作者视角”，我得到的机会是”更接近我自己“。
我还意识到，不是因为我不够专业而选择做各种杂事，反而是因为我有一种希望事情能够真的完成的责任感才选择去做所谓的”杂事“。项目需要有人完成的这些事，我去做了，现在一些非常商业化，非常细分的市场希望我只做过某件事，是某个领域的“专家”，但我没能选择这条道路。
我仍然想要找到自己作为创作者想要表达的事，于是我仍然在尝试通过做一些小游戏来创造一些体验，尝试进行一些表达。
虽然这个网站主要放一些工作的作品，但是这个关于我的部分，我决定还是真诚一些，少写一点”我做了什么，我是什么专家，我可以证明我有什么技能“这种冠冕堂皇的话。

# 关于本站

我一直对个人网站很有兴趣，这感觉就像是在赛博空间给自己搭了个小房子。即使它似乎对如今的国内就业市场几乎毫无帮助（bushi），但我惊喜地发现我对创造这个电子空间很有热情，我一直在想象来访者会如何点击我的网站。如今像我这样对前端代码一窍不通的人也能独立部署网站，不得不感谢 AI 技术的存在。
我用Obsidian来管理这个网站的文本信息，过程有点像策划在配表：在本地修改完文档，通过 GitHub 推送就能完成自动部署。虽然经常因为引用图片打错字而部署出错，但我依然为自己创建的这个“部分可持续”的方案感到开心。

现在这个赛博毛坯房还在持续更新中。无论如何，欢迎你来这里坐坐，请喝一杯电子热饮。
